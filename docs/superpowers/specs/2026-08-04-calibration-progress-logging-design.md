# Tracker–鱼眼相机标定进度与日志设计

## 目标

为 `calibrate_tracker_camera` 完整标定模式增加可持续观察的阶段进度、运行耗时和预计剩余
时间，同时把相同内容持久化到输出目录的 `calibration.log`。功能不改变检测、PnP、
Hand-Eye、联合优化或质量门的数学结果。

## 根因与约束

首次全量标定持续约 45 分钟但没有输出。调用链在进入
`scipy.optimize.least_squares()` 后保持高 CPU，说明进程仍在计算；缺少输出的直接原因是：

- CLI 只在流程结束时打印最终 JSON；
- 样本收集和时间粗扫没有进度回调；
- 系统 SciPy 1.11.4 的 `least_squares` 不支持 `callback`；
- 当前优化调用没有应用层残差计数或定时心跳。

实现继续使用系统 SciPy 1.11.4，不升级 ROS 环境依赖。联合优化的收敛次数事先未知，
因此不能承诺精确完成百分比。

## 组件设计

### 进度记录器

新增 `tracker_camera_progress.py`，提供聚焦的 `CalibrationProgressLogger`。该对象负责：

- 同时向标准输出和 `<output_dir>/calibration.log` 写 UTF-8 单行日志；
- 每行包含本地时间、阶段名、总耗时、阶段耗时和消息，并立即 flush；
- 管理阶段开始、定时更新、完成和失败；
- 使用单调时钟计算耗时，避免系统时间调整影响 ETA；
- 支持注入时钟，便于确定性测试；
- 通过 `close()` 释放文件句柄，即使异常退出也保留已完成日志。

默认心跳间隔为 30 秒，CLI 新增 `--progress-interval-seconds` 允许覆盖，必须为有限正数。
日志文件路径固定为输出目录的 `calibration.log`，避免额外路径配置。

### 阶段进度

完整模式依次记录：

1. `load_inputs`：读取相机、目标配置和 Tracker 时间线；
2. `collect_samples`：每处理 100 帧或达到心跳间隔时，输出已解码帧、有效样本和各拒绝计数；
3. `motion_and_seed`：输出运动去冗余帧数及入选五算法 Hand-Eye 初值的方法和误差；
4. `time_offset_scan`：每个候选偏移完成后更新 `已完成/总点数`、百分比、当前最佳偏移和
   根据平均单点耗时计算的 ETA；
5. `joint_optimization`：在残差函数外包一层计数器，每 30 秒输出残差调用次数、近似基础
   函数评估数、当前残差 RMS、处理速率和保守上限 ETA；
6. `diagnostics_and_report`：输出诊断计算与报告文件生成状态；
7. `complete`：输出总耗时、质量门结果和报告目录。

检测预检模式保持现有最终 JSON，同时记录 `detect_only` 阶段开始、定时帧计数和完成状态。

## ETA 语义

- 时间粗扫的总点数已知，ETA 按已完成点的平均耗时计算，属于动态估计。
- 联合优化没有 callback。13 个参数采用两点数值差分，记录器以 14 次残差调用近似一次
  基础函数评估，并按 `max_nfev=2000` 计算保守上限 ETA。
- 联合优化日志必须使用“近似评估”和“保守上限 ETA”字样，不能把它展示为准确百分比。
- 优化自然收敛通常早于上限；日志同时输出 RMS 变化和实际速率，供人工判断是否仍在推进。
- 无法可靠估计时明确输出 `ETA=未知`，不制造虚假精度。

## 接口和数据流

优化模块新增可选进度回调，默认值为 `None`，现有调用和测试保持兼容。回调事件使用普通
字典，至少包含 `stage` 和阶段相关计数。CLI 将事件转换为用户日志，优化模块不依赖文件
系统或 Python logging 配置。

`scan_time_offset()` 在每个候选偏移结束后发出事件；联合优化包装残差函数，按记录器要求
发出定时事件，并在 `least_squares` 返回后记录真实 `nfev`、终止状态和消息。

## 错误处理

- 日志目录与完整输出目录一同创建；日志文件无法打开时立即报错，避免用户误以为已有日志。
- 标定阶段异常或质量门失败时，先记录 `FAILED`、阶段、原因和总耗时，再沿用现有失败摘要。
- Ctrl+C 通过 `finally` 关闭日志，已写内容继续保留；中断仍向上传播，不生成伪成功结果。
- 进度回调异常不得静默吞掉；测试确保错误可见。

## 测试策略

- 单元测试使用可控单调时钟验证阶段耗时、心跳抑制、百分比和 ETA 格式。
- 优化器测试验证时间粗扫按候选点发事件、联合优化至少发出开始与完成事件，并保持合成
  外参精度不变。
- CLI 测试验证 `calibration.log` 同时包含阶段名、总耗时和失败原因；非法心跳间隔被拒绝。
- 运行现有 74 项 pytest 和 colcon 测试，确认无回归。
- 重新构建 ROS 包后，使用原完整命令重跑；人工确认控制台持续输出、日志同步增长，最后
  再独立验证正逆外参、质量门和报告文件。

## 非目标

- 本次不升级 SciPy，不实现自定义优化器或解析 SciPy 私有内部状态。
- 本次不改变样本数量、优化上限、鲁棒损失、时间搜索范围或质量门。
- 本次不把保守 ETA 表述为保证完成时间。
